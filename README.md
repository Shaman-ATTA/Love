# 💌 Love Chat

Android-приложение для двоих: пишешь сообщение — у любимого человека оно сразу появляется в виджете на главном экране и всплывает поверх любого приложения. Соединение по секретному коду, сообщения шифруются (AES-GCM) ключом из кода.

## Что умеет (v1.1)
- Текстовые сообщения и 🎨 рисунки пальцем — в виджете, поверх любого приложения и в уведомлении
- Статус: подключён ли ты и в сети ли партнёр
- Понятные ошибки при отправке

## Установка
1. Скачай LoveChat.apk на оба телефона и открой. Если запрещено — «Настройки» → «Разрешить из этого источника» → «Установить» (при предупреждении Play Protect — «Всё равно установить»).
2. Открой Love Chat, разреши уведомления.
3. Один нажимает «Создать новый код» → «Поделиться кодом», второй вводит тот же код. Оба жмут «Подключиться ❤».
4. «Разрешить показ поверх приложений» → Love Chat → включить «Показывать поверх других приложений» (или Настройки → Приложения → Love Chat → «Поверх других приложений»).
5. «Отключить экономию батареи» → «Разрешить». На Xiaomi также включи «Автозапуск» и «Нет ограничений» для батареи.
6. Виджет: долгое нажатие на пустом месте главного экрана → «Виджеты» → Love Chat.

Работает через бесплатный сервер ntfy.sh, аккаунты не нужны.

## Xiaomi / Redmi / POCO (MIUI)
В приложении есть кнопки «Другие разрешения» и «Автозапуск». Включите «Отображать всплывающие окна, когда запущено в фоновом режиме», «Поверх других приложений», «Автозапуск», а в «Контроле активности» выберите «Нет ограничений».
